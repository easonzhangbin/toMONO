# RAW 单色响应与重建原理

## 颜色为什么会变成不同的灰？

可以把 Bayer 感光阵列想成铺着不同颜色滤光片的小格子。典型 2×2 单元有一格红、一格蓝和两格绿。每格只测到透过自己滤光片的光，并没有同时测到完整 RGB。

对某个采样位置，忽略饱和与复杂串扰时，其响应可以近似写为：

`测量值 = 曝光比例 × ∫ 入射光谱(λ) × 该类像素响应(λ) dλ + 黑电平 + 噪声`

改变通道权重，就改变了不同波段对最终灰度的贡献。但三条通道响应不是任意光谱的完整测量，所以无法仅靠三项权重精确重现任意实体单色传感器或胶片。滤镜、照明和物体光谱也会影响结果。

## toMONO 的处理流程

1. 用 LibRaw 读取 RAW，确定 CFA、有效区域、方向和黑白电平；不从 JPEG 亮度估计 RAW。
2. 将参与处理的采样按实际通道电平放到共同线性尺度，应用显式启用的缺陷修复等处理。
3. 根据模式形成目标响应：绿色响应输出G；RGB混合重建R/G/B后按归一化权重合成。C01、D11、D10只读取目标同色；普通照片可选的LMMSE内部会借助完整RGB采样。严格窄带只重建选定颜色，不允许LMMSE。
4. 应用用户明确指定的响应曝光和镜头处理，完成最终量化，写入单通道 DNG。
5. 为观看生成带显示变换的预览；显示曲线与线性 RAW 数值分开。

传感器本身的测量仍是实测，其他位置是估计。Bayer 的绿色采样约占一半，红蓝各占四分之一。插值补齐画面尺寸，不会增加实际采样数量；“子像素参与”不能解释为恢复了原本没测到的全部细节。

## 细节计算与已知取舍

新照片与复位默认D10。C01 按 G 的棋盘格 / 菱形频域支撑与 R/B 的规则子格设计有限支撑重建核，分块时保留边界重叠，并做相位直流归一化。D11 对缺失位增加同色实测邻域范围约束。D10 对绿色估算方向可信度并融合横纵预测；红蓝保持有界三次回退。这些方法都不能唯一拆开采样前已经发生的频谱混叠。

重建核保留目标色实测约束，但前面的显式坏点与绿色校正、后面的曝光、混合、几何重采样和量化可以改变最终像素。严格窄带跳过绿色差异校正，不读其他颜色作结构引导。常规绿色差异校正可按红蓝区域条件判断是否处理，不能把整个常规管线称为严格同色。

LMMSE实验选项实际采用Getreuer的IPOL参考实现，依据Zhang–Wu方法估算水平/垂直G−R、G−B颜色差及局部误差，再作统计融合。它会借助其他颜色：普通自然纹理可能更准确，颜色不相关细纹则可能产生伪绿色结构，高光仍可能过冲。它不是C01/D10的同色近似，也不用于窄带独立纯通道。原理论见 [Zhang与Wu 2005](https://doi.org/10.1109/TIP.2005.857260)，实际代码与实现说明见 [Getreuer/IPOL 2011](https://doi.org/10.5201/ipol.2011.g_zwld)，[完整采用关系](RESEARCH.md)另列。

切换模式时的局部检查放大镜只在同一位置比较缓存原生像素；反差、纹理启发式选出的区域是检查建议，不证明该处存在伪影，也不自动切换算法或修改RAW。

## 窄带底片翻拍

分别用红、绿、蓝窄带光源拍三张 RAW。红光照片选择 R，绿光选择 G，蓝光选择 B；各自输出单通道 DNG，再在 NegPy 指定通道合成。三张输入不是同一光谱条件下的重复曝光，不能直接当作同光源多帧超分观测混合。

此路径的目标是限制软件重建阶段的通道混合。不同光源功率、滤色片透过率和曝光造成的亮度差保留在输出中，不自动归一成同样明亮。蓝光低信号带来的噪声也不会凭空消失；提高 EV 会同时放大噪声并可能剪裁高光。

## 噪声与外观

单通道输出消除了 RGB 色彩噪声的显示形式，但不保证噪声变成独立随机“胶片颗粒”。插值会改变噪声的空间相关性，仍可能出现周期纹理、棋盘格、振铃和摩尔纹。本版没有新增训练模型。C01/D11/D10不自动估噪；LMMSE使用原算法的颜色差残差统计，不能把它称为已经标定的传感器噪声模型。

RAW 数据通常与曝光近似成比例，不能直接按显示器编码观看；预览需要黑白归一化、伽马 / 显示变换及色彩管理。不同 RAW 软件还会应用自己的曲线与默认值。toMONO 将获认可的预览外观作为目标，并为 ACR 写入初始显影参数；这类元数据可能被忽略、覆盖或重置，不代表所有软件必然显示相同灰度。
