## 历史公开快照（Beta 8.1）

Beta 8.1 基于 Beta 8 计算引擎，增加开源说明、可独立构建的配置和自愿支持页面。未改变三种细节算法或 RAW 显示曲线；DNG 的 Software 版本标记更新为 Beta 8.1。

在独立源码目录、uv 管理的 Python 3.12.13 和锁定依赖上运行：

```sh
./scripts/bootstrap.sh
./scripts/test.sh
```

当时结果：后端共 92 项测试，89 项通过，3 项私人实拍样本集成测试明确跳过。194 组产品 / 冻结参考核对照中，C01 / D11 最大绝对误差为 1.1920928955078125e-7，D10 为 0；容差为 5e-7（归一化信号单位）。这验证移植与分块计算一致性，不代表每种场景的真实细节提升。Swift 实际配方与队列值类型检查同时通过，涵盖默认 C01、旧预设迁移、逐张设置、缓存参数和保存状态。

`scripts/build_references.py` 先核对两组冻结参考源码的 SHA-256，再构建本机库；不会修改冻结源码。私有样片没有提交。可显式设置 `TOMONO_SAMPLE_DIR` 运行相关集成测试，缺少指定文件时跳过，不访问开发者硬编码路径。

完整本地应用构建、内置 Python / LibRaw / Lensfun 导入和 C 核加载通过，Xcode Debug 构建通过。`scripts/smoke_app.py` 使用生成的 128×128 Bayer DNG，经打包应用私有后台完成导出，独立 LibRaw 回读通过，实测绿色位置逐像素一致，源文件摘要未变。当前验证使用 Xcode 27.2；不将命令行构建等同于 Canvas 交互测试或所有 macOS 版本真机测试。

支持页使用实际 SwiftUI View 在独立 QA 窗口渲染，核对深浅色显示和原图资源一致性。二维码检测用于验证可读性，不验证收款账户状态，不执行支付。没有远程支付回调或功能解锁机制。

## 历史研究的取舍

| 模式 | 已观察到的价值 | 需要保留的失败条件 |
| --- | --- | --- |
| C01 频域精细 | 部分合成带宽内细线、实拍织纹表现较好 | 高反差振铃、噪声增益和混叠变化 |
| D11 频域限幅 | 限制局部预测过冲 | 可能压低真实极值、丢失纹理，周期场景仍有相位偏差 |
| D10 方向自适应 | 部分边缘预测更稳定 | 周期织纹退化；红蓝并非新的 AR 方法 |

公开仓库保留冻结参考核与用于展示的实拍显示图，不附带原始实拍 RAW、训练集、历史完整输出或第三方模型。首页对比图由当前产品核重新生成，条件见 [图库](GALLERY.md)。应用中原有研究记录明确标注日期与范围，不能用本次单元测试替代历史实拍评价，也不能把无真值的主观观感解释成逐像素精度证明。

## 新算法比较建议

比较时固定原始文件、有效裁切、曝光与显示曲线；关闭不属于比较对象的坏点、绿色校正和镜头处理。分别检查实测位与缺失位，记录边缘过冲、相位偏差、频谱、噪声相关性和运行资源。加入斜边、周期织纹、文字、平滑暗部、饱和高光及窄带样本；成功和失败场景一起报告。

ACR 初始显影参数沿用此前研究适配，本次未重新进行 ACR / Capture One 实机灰度一致性验收，不宣称跨软件 100% 一致。
