# 源码范围与来源

本仓库是从 Beta 8 开发树整理并加入支持页面的 Beta 8.1 源码发布快照。保留了当前 SwiftUI 应用、Python 转换管线、C 数值核和两组冻结的同色研究参考核。

- C01、D10、D11 是本项目独立编写的确定性研究实现。文献提供采样、方向预测与局部约束等思路；这些实现不是所引论文的完整复现，也不继承论文的质量成绩。
- `legacy` 兼容路径起源于早期行为分析与数值兼容实验。公开的 C / Python 文件是本项目的重新实现，不能把这段历史称为完全无参照的独创算法。运算次序和边界行为保留以支持旧预设；本仓库不包含被分析程序的可执行文件、对象代码、反汇编清单或资源。
- `robertson_table.json` 是 Robertson 色温计算使用的数值表，属于白点兼容路径的数据，不是机器学习权重。DNG 标签和白点处理见研究索引中的 DNG / 颜色资料。
- LibRaw、rawpy、NumPy、tifffile、imagecodecs、Lensfun、ExifTool、Python 等由独立项目提供。源码仓库声明依赖，不把这些项目整体改署为 toMONO。
- `macos/assets/ResearchReferences.json` 记录产品集成、历史实验与仅参考材料的区别。历史神经网络权重、训练数据、原论文 PDF 和第三方研究代码不在此次源码快照中。
- 个人相机照片、样片输出、日志、包含文件路径和序列号的实验记录未发布。对私人照片的历史评价不能由公共合成测试独立证明，公开说明保留这一限制。
